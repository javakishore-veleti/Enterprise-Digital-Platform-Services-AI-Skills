# Prompting Standard

Prompt Engineering:

Factors to consider - effort, adaptive thinking defaults, tool use,

## General principles
- Give LLM a role
- Use precise and direct prompts
- Long context prompting - Put longform data at the top

## Tool use
- Optimize parallel tool calling

## Thinking and reasoning
- Consider moving to adaptive thinking
  - (adaptive thinking 'vs' extended thinking)
- Minimizing hallucinations in agentic coding (`<investigate_before_answering>`)

## Model-specific guidance
- Response length and verbosity
- Calibrating effort and thinking depth (max > xhigh > high > medium > low)
- Tool use triggering
