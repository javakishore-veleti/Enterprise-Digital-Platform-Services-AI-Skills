# Prompt Engineering Operating Model

A Prompt Engineering Operating Model defines how AI is instructed, how context and reasoning are managed, when tools are used, how investigations execute, and how conclusions are verified.

| Control | Engineering Standard |
|---|---|
| Instructions | Role, objective, scope, constraints, and expected outcome |
| Context | Provide relevant application and runtime context |
| Reasoning | Match reasoning effort to task complexity |
| Tools | Retrieve code, configuration, logs, traces, metrics, and runtime state |
| Execution | Parallelize independent calls; sequence dependent calls |
| Verification | Investigate before answering; distinguish evidence, inference, and unknowns |

## Three-Layer Model

1. **Enterprise Digital Platform AI Skills** — **HOW**
2. **.digital-platform-ai/** — **WHAT / WHERE / INSTRUCTIONS**
3. **Application + Runtime** — **EVIDENCE**
