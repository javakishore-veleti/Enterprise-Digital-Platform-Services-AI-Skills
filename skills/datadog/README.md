All public skill names use the `datadog-` prefix.

The primary operating principle is evidence before conclusion: logs, traces, metrics, events, and correlated runtime state are evidence; an error message alone is not automatically proof of root cause.

Some capabilities depend on which Datadog products are licensed and enabled in the enterprise. Skills must verify availability rather than assume every Datadog module is enabled.
