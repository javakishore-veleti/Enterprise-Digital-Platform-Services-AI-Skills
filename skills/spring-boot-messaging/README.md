# spring-boot-messaging

Enterprise Digital Platform AI capability family for Spring messaging abstractions, Kafka, AMQP, Event Hubs adapters, consumers/producers, retries, DLQ/DLT patterns, and event-driven integration.

Public skills created inside this folder must use the `spring-boot-messaging-` prefix when the capability name alone could be ambiguous. Cross-stack concerns should route to the owning technology family rather than duplicate platform-specific knowledge.
