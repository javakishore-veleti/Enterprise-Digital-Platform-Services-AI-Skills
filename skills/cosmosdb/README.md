# Azure Cosmos DB Skills

Enterprise Digital Platform AI skills for Azure Cosmos DB.

## Entry Points
- `cosmosdb-inspect-account` - resolve account/database/container context
- `cosmosdb-diagnose-runtime` - end-to-end runtime diagnosis

## Data Architecture
- `cosmosdb-analyze-data-model`
- `cosmosdb-analyze-partitioning`

## Query, Indexing, Throughput and Cost
- `cosmosdb-analyze-query`
- `cosmosdb-analyze-indexing`
- `cosmosdb-analyze-throughput`
- `cosmosdb-analyze-cost`

## Consistency, Distribution and Events
- `cosmosdb-analyze-consistency`
- `cosmosdb-analyze-global-distribution`
- `cosmosdb-analyze-change-feed`

## Application Integration and Security
- `cosmosdb-analyze-sdk`
- `cosmosdb-analyze-security`

## AI Search
- `cosmosdb-analyze-vector-search`
- `cosmosdb-analyze-full-text-hybrid-search`

All public skills use the `cosmosdb-` prefix so the enterprise slash-skill namespace remains unambiguous.

Use the current service repository and `.digital-platform-ai/cosmosdb.yaml` as service-specific context. Runtime mutations require explicit authorization.
