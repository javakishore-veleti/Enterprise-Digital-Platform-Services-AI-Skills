# Analyze Atlas Access

1. Identify user/service identity, project, deployment, database privileges, and failing operation.
2. Inspect Atlas project access separately from database access.
3. Evaluate database roles and authentication mechanism.
4. Inspect SSO/federation or cloud identity integration only when configured.
5. Correlate access failures with network and audit evidence.
6. Never expose passwords, API keys, private keys, or tokens.

## Output
- Identity Context
- Project Access
- Database Authorization
- Failure Layer
- Recommended Action
