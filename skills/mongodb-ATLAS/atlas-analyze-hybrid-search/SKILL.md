# Analyze Hybrid Search

1. Identify lexical and vector retrieval paths and the business relevance objective.
2. Inspect search/vector index definitions and shared metadata filters.
3. Evaluate score combination or rank-fusion approach supported by the deployed Atlas capabilities.
4. Measure retrieval quality against representative queries.
5. Compare latency and quality with lexical-only and vector-only baselines.
6. Keep generation evaluation separate from retrieval evaluation.

## Output
- Hybrid Retrieval Design
- Lexical/Vector Evidence
- Fusion/Ranking Findings
- Quality/Latency Comparison
- Recommended Action
