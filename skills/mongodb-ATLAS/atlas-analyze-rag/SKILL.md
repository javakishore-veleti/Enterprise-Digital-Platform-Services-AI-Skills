# Analyze Atlas RAG

1. Trace ingestion, chunking, metadata, embedding, indexing, retrieval, reranking, and generation.
2. Verify embedding model/version and index compatibility.
3. Evaluate retrieval separately from answer generation.
4. Inspect metadata filters, tenant/security boundaries, and freshness.
5. Require grounded evaluation with representative questions and expected evidence.
6. Route vector/search mechanics to focused Atlas skills.
7. Never infer source grounding from fluent output.

## Output
- RAG Pipeline
- Retrieval Evidence
- Grounding/Evaluation
- Security/Freshness Findings
- Recommended Action
