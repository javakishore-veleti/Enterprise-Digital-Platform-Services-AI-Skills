# Analyze Data Federation

1. Identify federated database configuration and underlying data sources.
2. Inspect mappings/schemas, credentials/references, and cloud storage access.
3. Analyze query shape, pruning/pushdown opportunities, scanned data, and latency.
4. Separate live operational queries from analytical/federated workloads.
5. Evaluate cost and performance implications of broad scans.
6. Never expose cloud-storage credentials.

## Output
- Federated Topology
- Source/Schema Findings
- Query/Scan Findings
- Security/Cost Considerations
- Recommended Action
