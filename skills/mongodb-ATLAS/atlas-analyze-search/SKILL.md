# Analyze Atlas Search

1. Identify search requirements, indexed fields, mappings, analyzers, and query operators.
2. Inspect index state and query behavior.
3. Evaluate relevance, tokenization, scoring, facets, synonyms, and autocomplete as applicable.
4. Correlate search latency with index/query complexity.
5. Distinguish Atlas Search behavior from standard MongoDB query/index behavior.
6. Validate relevance changes with representative search cases.

## Output
- Search Index
- Query/Relevance Findings
- Performance Findings
- Coverage Gaps
- Recommended Action
