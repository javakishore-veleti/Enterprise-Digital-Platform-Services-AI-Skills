# Analyze Atlas Monitoring

1. Identify available Atlas metrics, logs, alerts, query telemetry, and application traces.
2. Verify coverage for resource saturation, connections, replication, query latency, storage, and network behavior.
3. Correlate Atlas signals with application requests and deployments.
4. Inspect alert thresholds and missing telemetry before declaring health.
5. Route Datadog-specific analysis to `datadog-*` skills.
6. Avoid collecting sensitive document contents.

## Output
- Monitoring Coverage
- Key Atlas Signals
- Application Correlation
- Alert/Telemetry Gaps
- Recommended Action
