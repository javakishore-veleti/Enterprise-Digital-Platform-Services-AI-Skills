# Analyze Spring Boot Atlas Integration

1. Trace Spring Data/Java driver configuration and affected query paths.
2. Identify SRV connection configuration, TLS, authentication reference, pool settings, timeouts, read preference, and concerns.
3. Inspect query shapes and index support.
4. Correlate application exceptions with Atlas metrics, networking, failover, and access evidence.
5. Distinguish application pool/configuration problems from Atlas platform/database problems.
6. Route generic framework issues to `spring-boot-*` skills.
7. Never expose credentials or complete sensitive connection strings.

## Output
- Integration Flow
- Driver/Pool Configuration
- Query/Concern Findings
- Atlas Correlation
- Recommended Action
