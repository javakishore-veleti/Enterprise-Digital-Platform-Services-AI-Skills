# Analyze Atlas Networking

1. Resolve application network, Atlas provider/region, private connectivity model, DNS, and access lists.
2. Inspect peering/private endpoint state and route/DNS assumptions.
3. Verify Atlas network access configuration and cloud-side security controls.
4. Distinguish DNS, routing, TLS, authentication, and database failures.
5. Do not broaden public IP access as a troubleshooting shortcut.

## Output
- Network Path
- Private Connectivity State
- Access/DNS Findings
- Failure Layer
- Recommended Action
